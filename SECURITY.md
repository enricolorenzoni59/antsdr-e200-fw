# Security

This developer preview has no supported binary release. The development profile
uses root/analog, static 192.168.1.10 and unauthenticated IIO networking. Run on
a trusted receiver LAN. The optional RAM spectrum service is not part of the
release and exposes unauthenticated HTTP control when started explicitly.

Do not include credentials, private keys, full environment dumps or sensitive
UART transcripts in public reports. Use GitHub private vulnerability reporting
if enabled; otherwise request a private contact channel from the maintainer
without publishing vulnerability details. Supported versions will be listed
here when a qualified release is available.
